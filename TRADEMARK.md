## "daraja-js" name use

The name and logo of this project identify *this* project. You may:

- State that your software "uses daraja-js" or "is built with daraja-js."
- Link to this repository and the npm package.
- Reference the name in articles, talks, and tutorials.

You may **not**:

- Name your own fork, product, or service "daraja-js" or anything confusingly similar in a way that implies it is the official project.
- Use the name or logo to imply endorsement of your product by this project's maintainers.
