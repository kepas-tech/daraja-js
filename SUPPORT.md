# Support

Where to take what:

| You have… | Go to |
|-----------|-------|
| A question ("how do I…") | [GitHub Discussions → Q&A](https://github.com/nellylemmy/daraja-js/discussions/categories/q-a) |
| An idea or proposal | [Discussions → Ideas](https://github.com/nellylemmy/daraja-js/discussions/categories/ideas) |
| A reproducible bug | [Open an issue](https://github.com/nellylemmy/daraja-js/issues/new/choose) (bug template) |
| A feature request | [Open an issue](https://github.com/nellylemmy/daraja-js/issues/new/choose) (feature template) |
| A design change with tradeoffs | RFC issue template |
| A security vulnerability | **Not here** — see [SECURITY.md](./SECURITY.md) |

We do not provide private 1:1 support. Asking in public helps the next person hit the same wall.

This is an independent toolkit. For Daraja API access, credentials, or account problems, contact **Safaricom** directly — we cannot help with those.
