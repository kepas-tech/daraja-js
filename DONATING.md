# Supporting daraja-js

`daraja-js` is free and Apache 2.0. If it saved you an outage, you can fund its
maintenance. Donations are voluntary and buy no support guarantees or influence
over the roadmap.

## M-Pesa (works today)

Pay directly to our Safaricom PayBill — the same rail this SDK is built on.

| Field | Value |
|-------|-------|
| **Business No. (PayBill)** | `4052037` |
| **Account No.** | `daraja` |
| **Amount** | your choice |

On your phone: **M-Pesa → Lipa na M-Pesa → Pay Bill → Business no. `4052037` → Account no. `daraja` → enter amount → PIN.**

Use account `daraja` so we can tell SDK donations apart from other traffic on
the PayBill.

## International

M-Pesa is Kenya-only. Cross-border donation rails (e.g. Polar, GitHub Sponsors)
are not set up yet — if you want one, open a [Discussion](https://github.com/kepas-tech/daraja-js/discussions)
and we'll prioritize it.

## Other ways to help (free)

- File precise bug reports with scrubbed payloads.
- Pick up a [`good-first-issue`](https://github.com/kepas-tech/daraja-js/labels/good-first-issue).
- Tell other Kenyan developers it exists.
